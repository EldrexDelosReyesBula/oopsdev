# Digital Rescue Crew

**Website Name:** Oops.dev
**Logo Concept:** Minimal lifebuoy with pixel segment
**Tagline:** "Rescue. Digitalize. Keep."
**Overall Vibe:** Friendly, reassuring, clean, modern, and approachable
**Primary Users:** Philippine MSME owners and LGU staff who are not tech-savvy but want to modernize

## Website Structure (One-Page Layout)

### Section 1: Hero Section

**Purpose:** Grab attention immediately and explain what you do in 5 seconds.

**Content:**

- **Headline:** "We Fix Your Oops."
- **Subheadline:** "We rescue your business from slow, manual processes—and keep every record safe while bringing you into the digital age."
- **CTA Button (Primary):** "Get Rescued Today" (Rescue Red background, Paper White text)
- **CTA Button (Secondary):** "See How It Works" (outline style, Trust Navy border)
- **Visual:** Large, friendly illustration of the Rescue Buoy logo with a paper document being pulled into a digital screen
- **Background:** Paper White with subtle wave or dot pattern

---

### Section 2: The Problem

**Purpose:** Make visitors feel understood and validated.

**Content:**

- **Section Title:** "Sound Familiar?"
- **Subtext:** "You're not alone. Many businesses are stuck in paper chaos."

**Three Problem Cards:**

| --------- | ------------------- | ----------------------------------------------------------------------- |

| ❌        | Costly Errors       | "One wrong entry can mess up your whole inventory or report."           |

**Style:** Three simple cards with emoji or line icons, Trust Navy text on Paper White cards with soft shadow

## Development

Requirements: **Node.js 18+** and **npm 9+**.

```sh
git clone <this-repository-url>
cd digital-rescue-crew-main
npm install
npm run dev         # Vite dev server
```

Other scripts:

```sh
npm run build       # Production client bundle in dist/
npm run lint        # ESLint
npm run format      # Prettier
```

## Tech Stack

| Layer        | Technology                                    |
| ------------ | --------------------------------------------- |
| Framework    | Kite via CDN (`https://esm.sh/@kitelet/core`) |
| Reference    | `@kitelet/core` (npm package)                 |
| Routing      | Kite Hash Routing (`<kite-route>`)            |
| State/Models | Kite Declarative MVCR (`<kite-model>`)        |
| Styling      | Tailwind CSS v4                               |
| Build Tool   | Vite 8 (`@tailwindcss/vite`)                  |

## Project Structure

```
index.html        Main entry shell with Kite configuration, models, routes, outlet
app/
  routes/         Route declarations (routes.html)
  models/         State models (team.model.html)
  views/          Screen view templates (home.view.html, about.view.html, story.view.html)
src/
  styles.css      Design tokens, Tailwind v4 theme, and button utilities
public/           Static assets served directly (logos, team photos, favicon)
vite.config.ts    Vite 8 build configuration with Tailwind CSS v4 & Kite include plugin
```
